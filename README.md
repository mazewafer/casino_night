# SE 101 Team Project — Fall 2026

This project is the **upstream** for every team repository. Your team fetches it once, in
Lab 5, and it gives you the structure below.

Everything lives in one directory, **Project/**. The warm-up exercise from Lab 5 and the
term project are the same codebase at different stages — you evolve it, you do not start
again.

    Project/
      README.md        what you are building and how it is marked
      docs/            charter, requirements, test plan, test report, retrospectives
      src/             your code
      tests/           your tests
      build/           anything generated (optional)

Read Project/README.md as a team before you write anything.

## Deadlines

All dates — charter, sprint reviews, final submission — are in the **SE 101 Deadlines
document on Learn**. No date appears anywhere in this repository, so that there is exactly
one place to look and exactly one place to change.
